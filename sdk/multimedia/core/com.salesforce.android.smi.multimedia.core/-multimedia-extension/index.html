MultimediaExtension

@RequiresApi(value = 26)
object MultimediaExtension : MultimediaCoreExtension

The entry point for multimedia capabilities in the Messaging for In-App SDK.

Pass this object as the multimediaExtension parameter when creating a com.salesforce.android.smi.core.CoreConfiguration to enable voice call support. Use configure to customize the MultimediaConfiguration before initializing the core client.

Requires Android O (API 26) or higher.
